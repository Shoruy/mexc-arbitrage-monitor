# NLM Re-Analysis: Актуальность 2025 vs 2026
**Дата:** 2026-05-07
**Новые источники:** GitHub crypto-arbitrage-bot + arbitrage-alert-bot (2026)

## Актуально (из 2025)
- Задержка MEXC 1-2 сек от Binance — структурная особенность
- Лимитные ордера, никаких маркетов
- Нулевые комиссии обязательны
- Антидетект + прокси

## Устарело
- ❌ **KYC не нужен** → теперь обязателен (массовая покупка верификаций)
- ❌ **Telegram-боты сигналов** → слишком медленно, нужны терминалы
- ❌ **DEX↔MEXC** → сменилось на Binance↔MEXC

## Новое в 2026
- РК отключает 0% комиссии при обороте
- **User ID** из cookies для MetaScalp
- GitHub боты с WebSocket + Redis (рабочий код)
- Deep Research: гео-блокировка Tier 2 для СНГ

## Рекомендации по коду
1. **WebSocket вместо REST** для MEXC
2. **User ID injection** для обхода блокировок
3. **Проверка "дырок" в стакане** в симуляторе
4. **Авто-сканирование 0% комиссий**
5. **Redis** для rate limiting
