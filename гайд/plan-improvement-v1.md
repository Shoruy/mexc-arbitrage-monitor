# План улучшения MEXC-Binance Spread Monitor — Прибыльность на аккаунте с -PNL

**Версия:** v1.0  
**Дата:** 2026-05-08  
**Основание:** Гайд по флипам альтов + эксплуатация задержки Binance → MEXC + live-монитор v7 (curl_cffi)  
**Аккаунт:** MEXC с -PNL (мин. -200$), депозит ~30$  
**Текущий софт:** `/root/bin/mexc-tg-monitor.py` v7, GitHub: `Shoruy/mexc-arbitrage-monitor`

---

## 1. Текущее состояние — что уже есть

### ✅ Работает
- Binance WebSocket (8 пар, реал-тайм)
- MEXC REST polling (1с, через curl_cffi — Cloudflare bypass)
- Сигналы в Telegram при спреде >0.12%
- Фильтр ликвидности (стакан, спред ≤0.05%, объём ≥$1000)
- Авто-трейдинг (leverage, order, close) через contract.mexc.com
- Риск-контроль: 1 поза, 20/день, стоп $3, пауза после 8 серий
- GitHub репозиторий с гайдами и API-шпаргалкой

### ❌ Не работает / не оптимизировано
- REST polling 1с — пропускает окна <1с (а их большинство)
- Только 8 пар — мало возможностей
- Спред 0.12% на альты — часто недостаточно для профита с учётом комиссий
- Нет разделения лимит/маркет ордеров (сейчас market — taker fee 0.01%)
- Нет учёта реальных комиссий MEXC (maker 0%, taker 0.01% на futures)
- Нет истории сделок и аналитики PnL
- Нет динамического размера позиции (всегда $7±$1)
- Нет auto-reconnect для curl_cffi если API временно падает
- Нет systemd автостарта
- Нет health-check монитора

## 2. Фазы улучшения

### Фаза 1: Стабильность и скорость (1-2 дня)

**Цель:** Не пропускать окна, гарантировать исполнение

| № | Задача | Описание | Приоритет |
|---|--------|----------|-----------|
| 1.1 | **MEXC WebSocket вместо REST** | Подключиться к `wss://contract.mexc.com/ws`. Раз в секунду — устаревшие цены. Binance WS даёт обновления 10/сек, MEXC REST — 1/сек. WS будет 10-20/сек. Спред будет точнее, вход раньше | 🔴 Critical |
| 1.2 | **Systemd unit** | `/etc/systemd/system/mexc-monitor.service` — автостарт, auto-restart, логи. Без этого монитор умирает при ребуте и при падении | 🔴 Critical |
| 1.3 | **Health-check + watchdog** | Монитор пишет heartbeat в /tmp. Systemd или отдельный скрипт проверяет alive. Если 2 проверки подряд нет heartbeat → restart | 🟡 Major |
| 1.4 | **Лимитные ордера вместо рыночных** | Сейчас `type: 1` (market) — taker fee 0.01%. На лимитных ордерах (type: 5 + postOnly) — maker fee **0%**. Разница 0.01% на сделку убивает ~8% профита при спреде 0.12% | 🔴 Critical |

### Фаза 2: Больше возможностей (2-3 дня)

**Цель:** Увеличить частоту срабатываний в 3-5x

| № | Задача | Описание | Приоритет |
|---|--------|----------|-----------|
| 2.1 | **Расширение списка пар** | Сейчас 8 пар. Аналитики MEXC: 100+ пар с 0% maker fee. Нужно отфильтровать по: ликвидности >$1000, спред <0.05%, 0% maker fee, есть на Binance. Можно 30-50 пар | 🟡 Major |
| 2.2 | **Умный фильтр пар** | Периодически (раз в час) проверять все доступные пары MEXC, отсеивать неликвидные, ранжировать по частоте спредов. Динамически держать топ-30 по активности | 🟡 Major |
| 2.3 | **Снижение порога входа** | Сейчас 0.12%. С MEXC WebSocket (точнее цены) + limit orders (0% fee) можно снизить до 0.06-0.08%. Это в 2x больше сигналов | 🟡 Major |
| 2.4 | **Два направления одновременно** | LONG и SHORT независимо. Сейчас одна сделка за раз на все пары. Можно 1 LONG + 1 SHORT одновременно (на разных парах) | 🟢 Minor |

### Фаза 3: Прибыльность и риск (2-3 дня)

**Цель:** Стабильный +PnL с учётом проскальзывания, комиссий и РК

| № | Задача | Описание | Приоритет |
|---|--------|----------|-----------|
| 3.1 | **Fee-моделирование** | Рассчитывать реальную прибыль с вычетом комиссий. Если спред 0.12%, taker fee 0.01% → чистая 0.11% × 20x = 2.2% к депозиту. Если entry через limit (0%) и exit через limit (0%) → 0.12% × 20x = 2.4% | 🔴 Critical |
| 3.2 | **Bid/ask cross вместо mid-price** | Сейчас сравниваются `(bid+ask)/2` обеих бирж. Реальный исполнимый спред: `ask(MEXC) - bid(Binance)` для LONG, `bid(MEXC) - ask(Binance)` для SHORT. Проскальзывание может съедать 0.02-0.05% | 🟡 Major |
| 3.3 | **Динамический размер позиции** | Сейчас всегда $7. Лучше: % от депозита (20-30% от -PNL баланса). Если -PNL = -500$, точина 100$ на сделку | 🟡 Major |
| 3.4 | **Трекинг PnL по сделкам** | База данных SQLite для каждой сделки: вход, выход, спред, комиссия, PnL. Аналитика: какие пары самые прибыльные, дневная/недельная статистика | 🟡 Major |
| 3.5 | **Адаптивный стоп-лосс** | Сейчас 0.20% от спреда = ~$0.42 на сделку. Лучше: стоп по расширению спреда (если спред не схлопывается за N секунд, а растёт → force close) | 🟢 Minor |

### Фаза 4: Account-Management (1-2 дня)

**Цель:** Защита аккаунта, обход РК, увеличение срока жизни

| № | Задача | Описание | Приоритет |
|---|--------|----------|-----------|
| 4.1 | **Имитация человеческого поведения** | Случайные задержки между сделками (+-50%), джиттер объёма (+-30%, а не +-$1), случайный выбор пары из топ-N, а не строгий порядок | 🟡 Major |
| 4.2 | **Мониторинг -PNL** | Если PNL аккаунта приближается к 0 (выход из зоны -PNL) — снизить частоту сделок. Если PNL положительный — остановить бота | 🔴 Critical |
| 4.3 | **Мониторинг 0% комиссии** | MEXC может убрать 0% maker fee в любой момент. Автоматически детектить изменение и переключаться в режим только сигналов (без торговли) | 🟡 Major |
| 4.4 | **Лимит объёма** | MEXC даёт ~20M объёма до проверки. Мониторить накопленный объём и снижать активность при приближении к лимиту | 🟢 Minor |

## 3. Технический стек (v8)

**Текущий стек (v7):**
- python3 + asyncio
- websockets (Binance)
- curl_cffi (MEXC REST)
- aiohttp (Telegram fallback)
- json files для логов

**Целевой стек (v8):**
- python3 + asyncio
- websockets (Binance WS)
- curl_cffi.AsyncSession (MEXC WS + REST fallback)
- SQLite (история сделок)
- Telegram API (aiohttp)
- systemd (автостарт + логи)

**Почему не ccxt:**
- ccxt использует requests (TLS fingerprint Python → Cloudflare бан)
- curl_cffi — единственная библиотека, проходящая Cloudflare contract.mexc.com

## 5. Риски

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| MEXC блокирует IP навсегда | Низкая | Полная потеря | Прокси ротация |
| РК после N сделок | Высокая | Блок фьючей | -PNL аккаунт, имитация человека |
| 0% комиссию убирают | Средняя | Стратегия ломается | Режим только сигналов |
| МЭР (Min Execution Ratio) | Средняя | Штраф | Не ставить лимитки далеко от рынка |
| Cloudflare меняет TLS fingerprint | Низкая | fallback на curl subprocess | curl_cffi обновления |
| VPS диск забивается | Средняя | Монитор падает | Systemd auto-restart + cleanup |
