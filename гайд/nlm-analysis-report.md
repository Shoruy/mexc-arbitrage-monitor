# NLM Analysis: MEXC-Binance Флипинг — Полный отчёт
**Источник:** NotebookLM анализ 6 источников (2 видео + 4 teletype + текст гайда)
**Дата:** 2026-05-07

## 1. TL;DR стратегии
Флипинг — высокочастотная арбитражная стратегия ручного скальпинга, эксплуатирующая технологическое отставание котировок MEXC (на 1-2 сек) от Binance. Для извлечения микроприбыли критически зависит от нулевых торговых комиссий, максимального плеча и специализированных терминалов. Из-за риск-контроля MEXC стратегия не масштабируется — лимит $20-30 чистой прибыли на один профиль.

## 2. Ключевые сигналы
- **Вход:** Binance двинулась → MEXC "завис" → вход
- **Запрещено:** если в стакане MEXC "дырки" (маркет-ордер убьёт прибыль)
- **Фильтр:** монета должна коррелировать с BTC/ETH
- **Монеты:** SOL, XRP, LTC, XLM, Pengu, Aster, ZEC, XMR, BCH, HYPE (только с 0% комиссией)
- **Время:** ночь 23:00-07:00 (умеренная волатильность)

## 3. Техническая реализация
- **Терминалы:** MetaScalp, Stakan.io
- **Анализ:** визуально (2 синхронизированных стакана)
- **API MEXC:** требует API Key + Secret Key + User ID (из Cookies, F12)
- **Горячие клавиши:** D=лонг, F=шорт, Ctrl=закрыть всё
- **Пинг:** 150-200 мс (макс 300, свыше 400 — не работает)
- **Антидетект:** AdsPower + прокси под гео аккаунта

## 4. Риск-менеджмент
- **Стоп-лосс:** обязателен (иначе ликвидация за минуты)
- **Тейк:** чуть раньше полного схождения, остаток в безубыток
- **Плечо:** x50-x300 для MEXC/Binance (изолированная маржа)
- **РК MEXC:** бан фьючей, отключение 0%, запрос KYC
- **Аккаунты:** только с -PNL (от -$200), расходный материал

## 5. Экономика
- **Сделка:** $0.60-0.70, 4-5 сделок/мин
- **6 часов:** ~$150 грязными, ~$90-120 чистыми
- **Комиссии:** критически важны 0%, иначе сделка убыточна
- **Депозит:** $4-30 на аккаунт (не USDT, в случайном токене)
- **Потолок:** $20-30 на аккаунт до бана
